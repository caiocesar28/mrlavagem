# MR Estética Automotiva

Site de uma página da MR Estética Automotiva (Park Way, Brasília-DF): serviços e preços, antes e depois, onde atendemos, perguntas frequentes e agendamento pelo WhatsApp.

HTML, CSS e JavaScript puros, sem etapa de build. Para ver localmente, abra `index.html` no navegador.

- `index.html`: conteúdo da página
- `estilo.css`: visual (cores e fontes da identidade "Hexa")
- `app.js`: menu, filtro de serviços, comparador de antes e depois e formulário que monta a mensagem do WhatsApp
- `img/`: fotos do estúdio e logos

## Publicar

Funciona direto no GitHub Pages: Settings → Pages → Deploy from a branch → `main` / raiz. Também pode ser importado no Netlify ou na Vercel sem configuração.
